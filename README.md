# AI-Powered Project Management Dashboard

A modern, full-stack project management application built by a single developer to streamline team workflows, task tracking, and project analytics using integrated artificial intelligence.

#Tech Stack

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
* **Backend:** Next.js Server Actions, Node.js
* **Database & ORM:** PostgreSQL, Prisma ORM
* **Authentication:** Auth.js (NextAuth.js)
* **AI Integration:** OpenAI API (GPT-4o-mini)
* **Deployment & Hosting:** Vercel

---

#Features

* **Responsive Dashboard Views:** Clean, mobile-friendly interface designed with Tailwind CSS, featuring real-time project analytics and task statistics.
* **Advanced Task Management:** Create, filter, sort, and prioritize tasks with custom labels and strict deadlines.
* **Secure Authentication:** Robust user workflows and protected routes managed via Auth.js and PostgreSQL.
* **AI-Powered Workflows:** Intelligent task summarization and automated description generation using the OpenAI API to reduce manual administrative overhead.
* **Persistent Data Storage:** Scalable relational database architecture built with PostgreSQL and managed safely through Prisma ORM.
